# BCC Shield 360

**Активная экосистема кибербезопасности для мобильного банкинга Банка ЦентрКредит.**
ITU Hackathon 2026 · BCC Bank.

Демо-приложение на Next.js 14 (App Router) + React 18 + TypeScript + Tailwind CSS.
Один экран содержит мобильный интерфейс банка (395 × 852) и «Пульт симуляции атак»
для жюри, который в реальном времени меняет риск-профиль клиента.
На смартфоне интерфейс разворачивается на весь экран, а пульт жюри открывается
плавающей кнопкой **⚡ Пульт жюри**.

## Что внутри

| Модуль | Назначение |
| --- | --- |
| **Unified Risk Engine** | Складывает независимые факторы риска в единый балл 0–100 и выбирает решение: `ALLOW` → `COOL_DOWN` → `GUARDIAN_APPROVAL` → `BLOCK`. |
| **Transfer + SafeCall** | Переводы с защитой от телефонного мошенничества: баннеры активного вызова, вставка из буфера, кулдаун 10 секунд и три контрольных вопроса. Кулдаун вынесен в изолированный подкомпонент — таймер не перерисовывает телефон и не сбивает фокус ввода. |
| **Live Audio-to-Text** | Потоковая «расшифровка» звонка: реплики мошенника появляются каждые 2.5 с с бейджами `[Имитация госорганов]`, `[Запугивание]`, `[Реквизиты дроппера]`; верифицированный звонок BCC показывает зелёный поток с кодовым словом. |
| **TrustLens** | Анти-спуфинг радар, кодовое слово `АЛТЫН-739`, криптографическая квитанция, проверка подписи и раскрывающийся **крипто-паспорт HMAC-SHA256** с канонической строкой, сохранённым и пересчитанным хешем. |
| **GuardPay** | Семейный мульти-подпись: замороженный платёж на 380 000 ₸, одобрение или блокировка, счётчик спасённых средств и выгрузка рапорта в НБ РК по заблокированному платежу. |
| **AI Scam-Scanner** | Разбор казахстанских скриптов мошенников (RU + KK), подсветка триггеров, API `/api/scam-analyze` и активация повышенной защиты. |
| **On-Device PII Scrubber** | ИИН (12 цифр) и PAN карты (16 цифр) маскируются на устройстве до отправки в ИИ: `[ИИН СКРЫТ ЗАЩИТОЙ ПДн РК]`, `[КАРТА СКРЫТА]`. |
| **NBRK Antifraud Report** | JSON-пакет `NBRK-ANTIFRAUD-EXCHANGE-V2` для Антифрод-центра Нацбанка РК: `reportId`, `bankBic: KCJBKZKX`, `suspectPan`, `victimProfile`, `riskScore`, `synergyBoostTriggered`, `telemetryFlags`, `resolution: PREVENTED_BY_BCC_SHIELD_360`. |
| **RU / ҚАЗ** | Типизированный словарь `DICT` для навигации, статусов риска, баннеров, кнопок и карточек; выбор языка сохраняется между сессиями. |
| **PWA** | `app/manifest.ts`: `display: "standalone"`, `theme_color #00A859`, `background_color #0B1F17` — приложение открывается с домашнего экрана без адресной строки. |

### Формула риска

```
неизвестный звонок        +35
вставка из буфера         +20
сумма ≥ 200 000 ₸         +20
новый получатель          +15
недавнее предупреждение   +25
уязвимый профиль          +15
синергия «звонок + буфер» +15
─────────────────────────────
максимум                  100
```

Порог принятия решения:

- `0–29` — **ALLOW**
- `30–59` — **COOL_DOWN**
- `60–84` — **GUARDIAN_APPROVAL**
- `85–100` — **BLOCK**

### Криптография

Подпись квитанции считается реальным `HMAC-SHA256` через Web Crypto API:

```
canonical = `${id}|${timestamp}|${sender}|${recipient}|${amount}|BCC-2026`
signature = "BCC-" + первые 16 hex-символов, разбитые по 4
```

Ключ: `BCC-SHIELD-360-MASTER-CRYPTO-KEY-2026-KZ`.
При изменении суммы квитанции проверка возвращает `isValid: false`, фактический
хеш пересчитывается и окрашивается в алый цвет, а паспорт выводит сообщение о
лавинном эффекте SHA-256. Кнопка «Вернуть оригинальную сумму» восстанавливает
исходный чек.

## Персистентность и сброс демо

Состояние демо хранится в `localStorage` под ключом `bcc_shield_360_state_v2`:
баланс, баланс семьи, проведённые переводы, очередь GuardPay, счётчик спасённых
средств и выбранный язык. Запись начинается только после монтирования клиента,
поэтому SSR и первый клиентский рендер совпадают (hydration-safe).

Кнопка **«🔄 Сбросить демо к исходному состоянию»** есть в панели жюри и в
мобильной шторке. Она удаляет снапшот, выключает все тумблеры атак, возвращает
баланс к `1 450 000 ₸`, очищает операции, обнуляет счётчик спасённых средств и
восстанавливает подозрительный перевод от Апашки на `380 000 ₸` в очереди
GuardPay.

### AI-сканер (опционально)

Без ключа API работает детерминированная матрица казахстанских мошеннических
паттернов — демо никогда не падает. PII-скраббер выполняется в любом случае:
сырой ИИН и номер карты не уходят в LLM.

Чтобы подключить LLM, создайте `.env.local`:

```bash
OPENAI_API_KEY=sk-...
```

Маршрут `POST /api/scam-analyze` получает уже обезличенный текст, объединяет
ответ модели с правилами и возвращает поле `aiAssisted: true`.

## Сценарии для жюри

1. **Шторм атаки.** Нажмите **«Идеальный шторм»** — включится неизвестный
   звонок, вставка из буфера и сумма 450 000 ₸. Риск уходит в `BLOCK`,
   перевод блокируется с объяснением каждого фактора.
2. **Живая транскрипция.** Включите «Неизвестный звонок» — под красным баннером
   последовательно появляются три реплики мошенника с бейджами. Переключите на
   «Официальный звонок BCC» — поток станет зелёным с кодовым словом.
3. **Крипто-паспорт.** В TrustLens раскройте `🔐 Открыть крипто-паспорт
   HMAC-SHA256`, затем нажмите «🛠 Подделать сумму в чеке» — фактический хеш
   изменится, появится красное предупреждение о фальсификации.
4. **Безопасный перевод.** Сбросьте атаку, выберите доверенного получателя и
   сумму ниже 200 000 ₸ — решение `ALLOW`, квитанция подписана.
5. **Кулдаун.** Неизвестный получатель + карта из WhatsApp + 250 000 ₸ →
   `COOL_DOWN`: таймер 10 → 0, кнопка подтверждения заблокирована, пока не
   отмечены все три вопроса.
6. **GuardPay.** Заблокируйте замороженный платёж: счётчик спасённых средств
   вырастет на 380 000 ₸, в карточке появится кнопка рапорта НБ РК.
7. **Рапорт НБ РК.** Откройте JSON-пакет из модального окна `BLOCK` или из
   заблокированного платежа GuardPay, скопируйте его кнопкой
   «📋 Скопировать JSON рапорта».
8. **ПДн-скраббер.** В сканере выберите пресет «🪪 Тест ПДн: ИИН и карта» —
   в анализе видны токены `[ИИН СКРЫТ ЗАЩИТОЙ ПДн РК]` и `[КАРТА СКРЫТА]`,
   а исходные цифры не покидают устройство.
9. **Язык.** Переключите `RU | ҚАЗ` в шапке или в пульте жюри — интерфейс,
   статусы риска и баннеры полностью переводятся и сохраняются после перезагрузки.
10. **Сброс.** Нажмите «🔄 Сбросить демо» — баланс, очередь GuardPay и язык
    вернутся к исходному состоянию.

## Деплой на Vercel

1. Импортируйте репозиторий в Vercel.
2. Framework preset — **Next.js**, build command — `npm run build`.
3. При желании добавьте `OPENAI_API_KEY` в Environment Variables.
4. Deploy. `/manifest.webmanifest` генерируется автоматически из `app/manifest.ts`.
